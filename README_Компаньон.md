# PIVEN Companion

Локальное приложение для Windows на PySide6. Запускается файлом `desktop_companion.pyw` или ярлыком «Запустить компаньон». Для обычного чата нужна запущенная Ollama с установленной моделью.

Python 3.11.9 и библиотеки приложения находятся рядом с программой: `runtime\Python311`, `.qt_runtime` и `.packages`. Голосовые движки, их Python-окружение и модели также хранятся в этой папке. Ollama и ComfyUI остаются отдельными приложениями и должны быть установлены отдельно.

## Возможности

- Отдельные чаты: создание, переключение, закрепление, переименование, поиск и экспорт в Markdown или обычный текст.
- Автоматический выбор действия по запросу: обычный ответ Ollama, генерация изображения через ComfyUI, работа с файлами и кодом в режиме «Код», создание презентации PowerPoint.
- Настраиваемый уровень размышления для моделей Ollama, если модель сообщает поддерживаемые уровни.
- Озвучивание ответов, распознавание микрофона и системного звука, периодический анализ экрана.
- Навык управления компьютером: приложения, окна, файлы, консоль и веб-поиск. Скачивание файлов требует отдельного подтверждения перед началом.
- Twitch-интеграция для отправки одного подтверждённого сообщения: не чаще одного раза в 20 секунд, максимум 3 в час и 10 в сутки. Токен хранится только в памяти приложения.
- Темы рабочей доски: «Школьная зелёная доска», «Стандартная» и «Океан».

## Настройка

В **Настройки → Интеграции** включаются Ollama, ComfyUI и Twitch. Нажми на название интеграции, чтобы открыть её параметры. Для генерации изображений укажи адрес ComfyUI и API workflow в JSON. ComfyUI должен иметь нужные workflow узлы и модели.

В **Настройки → Код** выбери рабочую папку для агента разработки. Запросы на код обрабатываются относительно этой папки; абсолютный путь используется, если пользователь явно указывает другой файл или каталог.

В **Настройки → Голос и микрофон** выбери озвучивание, микрофон и чувствительность. Раздел **Экран** задаёт интервал анализа; для описания изображения нужна vision-модель.

## Создание файлов

Попроси создать презентацию обычным сообщением. Готовый `.pptx` сохраняется в `Документы/PIVEN/Презентации`; в карточке ответа доступны открытие и сохранение копии. Запрос на изображение отправляется в ComfyUI, результат показывается в чате и сохраняется в `%LOCALAPPDATA%\OllamaCompanion\generated_images`.

## Данные и журналы

Настройки, история чатов и журналы хранятся в `%LOCALAPPDATA%\OllamaCompanion`. При закрытии окна приложение сохраняет текущий чат. Запись микрофона и системного звука ведётся в памяти и не сохраняется в аудиофайлы.

## Новый веб-интерфейс

Ярлык «Запустить веб-интерфейс» открывает интерфейс на React в окне Windows (pywebview + WebView2). Он работает поверх того же движка `companion_core.py` и читает те же чаты и настройки из `%LOCALAPPDATA%\OllamaCompanion`: список чатов, переписку, выбранную модель, озвучивание, папку агента кода и интеграции. Из него можно писать модели, рисовать через ComfyUI, создавать презентации и запускать агента кода; останавливать ответ — крестиком на карточке или Esc.

Пока только в обычном окне: прикрепление изображений, микрофон и звук компьютера, наблюдение за экраном, скачивание файлов (нужно подтверждение), Twitch и полное окно настроек. Одновременно можно открыть только одно окно Компаньона — обычное или веб, чтобы они не перезаписали чаты друг друга.

Исходники интерфейса лежат в `modern-ui\src`; после правок пересобери его командой `modern-ui\scripts\build.cmd`.
