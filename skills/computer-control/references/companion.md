# PIVEN Companion: справка для агента

## Как устроен проект

- `companion_core.py` — движок без Qt: константы и пути, системные промпты, запросы к Ollama/ComfyUI/Parakeet, класс `CompanionCore` (загрузка и сохранение настроек и чатов, маршрутизация запросов, `ask_model`, агенты кода и презентаций, генерация изображений, озвучивание, захват звука и экрана, проверка разрешений для действий на компьютере). Фоновые потоки сообщают интерфейсу о результатах только через очередь `events`. Решения, требующие окна (подтверждение скачивания, прогресс, отложенное сохранение), вынесены в хуки `_confirm_download`, `_run_approved_download`, `_schedule_conversation_write`.
- `desktop_companion.pyw` — интерфейс на PySide6: `CompanionApp(QMainWindow, CompanionCore)` с рабочей доской, карточками, темами, окном настроек, обработкой `events` в `_drain_events` и реализацией хуков. Логику без Qt добавляй в `companion_core.py`, а не сюда; новый код ядра не должен импортировать PySide6.
- `web_companion.pyw` — второй интерфейс: окно pywebview с React-страницей `modern-ui/dist`. Класс `WebCompanion(CompanionCore)` разбирает очередь `events` так же, как `_drain_events` в Qt, а `WebApi` — единственные методы, которые видит JavaScript (`poll`, `send`, `select_chat`, `new_chat`, `set_model`, `set_speech`, `interrupt`, `image_data`, `open_file`). Исходники страницы — `modern-ui/src` (`App.tsx`, `bridge.ts`); после правок их нужно пересобрать `modern-ui/scripts/build.cmd`. Оба интерфейса берут блокировку `acquire_instance_lock`, поэтому одновременно открыт только один.
- `computer_skill.py` — исполняемые ограниченные операции с файлами и Windows, а также проектные действия `list`, `read`, `search`, `write`, `run`. Проверяй этот файл перед расширением инструментария.
- `presentation_skill.py` — создание и сохранение презентаций.
- `README_Компаньон.md` и `README.md` — пользовательские инструкции. Сверяй их с текущим кодом: старые описания режима или интерфейса могут отставать.
- `Архив/` — старые версии, прототипы, бэкапы и `PIVEN Companion Modern`; агент проекта его не обходит, ничего оттуда не запускается. Рабочие файлы — только в корне папки.
- `assets/` — ресурсы приложения, включая шрифты и графику; `skills/computer-control/` — этот системный навык и его справка.
- Пользовательские настройки, чаты, журналы и сгенерированные изображения хранятся в `%LOCALAPPDATA%/OllamaCompanion`, а не рядом с исходниками. Не редактируй эти данные напрямую без конкретной просьбы.

## Основные сценарии

- Текстовый ввод проходит через `send_text` и `_detect_composer_route`: обычный разговор, код, презентация или медиа. При необходимости смотри точный приоритет маршрутов в исходнике.
- Диалог с локальной моделью идёт через `ask_model` и `ollama_chat`; текущий список моделей и параметры размышления связаны с Ollama.
- Режим «Код» вызывает `_run_coding_agent`. По умолчанию агент изучает выбранный `project_root`; для явно названных пользователем путей разрешены абсолютные пути вне него. `project_action: roots` перечисляет доступные диски. Агент запрашивает действия JSON-объектами, меняет файлы через `execute_project_action` и может запускать только ограниченные проверки. Не обходи ограничения ОС, не читай секреты и не сканируй весь диск без необходимости.
- Управление Windows идёт через `COMPUTER_SKILL_PROMPT`, `ask_model`, `_execute_computer_actions` и `execute_computer_action`. Сначала проверяй пользовательское разрешение в коде приложения, затем добавляй новую возможность в исполнитель и описание навыка.
- Изображения создаются через `_start_image_generation` / `generate_image_via_comfyui` по workflow ComfyUI и добавляются на рабочую доску. Результаты сохраняются в пользовательской папке приложения.
- Презентации создаются `_run_presentation_agent` и `create_presentation` из `presentation_skill.py`.
- Вид карточек, соединителей и движение доски реализованы собственными классами Qt в `desktop_companion.pyw`; обновляй соединители после изменения геометрии карточек.

## Правила работы с кодом Компаньона

- Перед правкой найди конкретные функции и прочитай нужные участки исходника; не полагайся только на эту карту.
- Сохраняй формат текущего файла и совместимость с Python 3.11 и PySide6 из `.qt_runtime`.
- Новые возможности управления компьютером должны проверять явный запрос. Пути могут находиться на любом доступном диске, но обходи только область, нужную задаче. Скачивание обязано требовать отдельного подтверждения в интерфейсе и не перезаписывать файл.
- Не запускай скачанный файл, не устанавливай зависимости и не выполняй произвольный shell-код.
- После изменения `companion_core.py` или основного `.pyw` запусти проверку синтаксиса (`python -m py_compile`), если она доступна; изменения не видны в уже запущенном окне — Компаньон нужно перезапустить.
